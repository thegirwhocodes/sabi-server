What this is

Three different Sabis wore the same name

They are not versions of one architecture. Each generation moved the hardest job — deciding when a child has finished speaking — into a different box. That single choice is what changed the voice, the cost, the latency and the failure modes each time. The owner of that job is marked in gold on each path below.

The self-hosted rebuild

MAR 2026 · first commit 3b51788, 10 March

Everything moved onto one Hetzner box to kill the per-minute cost and make the child pay nothing. The tutor ran as a FastAGI application: record a turn, transcribe it, think, speak, repeat.

The call, stage by stage

What actually happens when the phone rings

The realtime lane, traced through the code that runs it. Every path and port here was read from asterisk/extensions.conf and main.py today.

  1. The trunk delivers the call

    A SIP trunk terminates on the box — 5060/udp for signalling, 10000-10100/udp for the audio itself. Two endpoints are configured, twilio and africastalking; which one dials out is chosen by SABI_SIP_PROVIDER.

  2. The dialplan asks the server what to do

    Contexts [from-at] and [from-twilio] both call POST /asterisk/inbound-route with the caller's number before doing anything else. The server answers with a route name.

  3. Flash callback, so the child never pays

    [sabi-flash] hangs the inbound leg up after a couple of seconds and fires POST /asterisk/flash, which queues an AMI originate. Four seconds later the phone rings back. A 45-second cooldown absorbs accidental double dials, and retries are off — one attempt only.

  4. The lesson leg opens a socket

    [sabi-inbound] registers the call with POST /asterisk/audiosocket/register, answers, then hands the channel to AudioSocket(uuid, sabi:9020). From here Asterisk is just a pipe.

  5. RealtimeCall takes over

    Raw 8 kHz frames arrive in voice_realtime.py. The class reads packets, watches energy and Silero for real speech, plays audio while still listening so barge-in works, and decides when a turn ended.

  6. The turn is transcribed

    transcribe_pcm routes to whichever recogniser the lane is configured for, with the lesson's own context as a hint — number words when a number is expected, name handling when a name is.

  7. Unclear audio is never marked wrong

    Carrier voicemail, hallucinated Whisper sentences and silence are all detected and answered with a repeat request. Two failed number attempts fall back to the keypad: type the digits and press hash.

  8. Sabi thinks

    llm.py runs the provider chain and is the only place the deterministic guardrails are applied — input checked before the model sees it, output checked before the child hears it.

  9. Sabi speaks

    tts_and_convert tries the configured primary and falls through the others, converts to 8 kHz WAV, and the frames go back down the same socket.

  10. The answer becomes evidence

    The turn is graded deterministically where it is numeric, written into the learner's state, and persisted with a per-turn sidecar recording which engine heard it and how long every stage took.

  11. The call ends and reports itself

    Asterisk's h extension posts to /asterisk/hangup with cause, duration and billsec. A teacher's note is written. The recordings stay on the shared audio volume for review.

Feedback, any time. The child or tester can press the hotkey or simply say "I want to leave feedback". Sabi stops, plays a go-cue beep, records the note, and files it against that exact call for review — built 22 June, hardened 29 June with a longer wait window, a retry and a DTMF skip.

The other half

The web app was a phone system too

Before the server existed, curriculum-app ran the whole tutor from Next.js API routes — and those routes are still there. Three complete telephony paths live in it: the ElevenLabs Custom LLM webhook, a pure TwiML record-and-respond loop, and an Africa's Talking record-and-respond loop.

ElevenLabs Custom LLM

/api/sabi/voice/llm — receives OpenAI-format messages from the agent, digs the caller ID out of the injected {{system__caller_id}} line, loads that child's memory, calls Claude, streams back in OpenAI format. This is the seam that gave the hackathon Sabi our curriculum and her memory while ElevenLabs kept her voice.

Twilio TwiML loop

/voice/incoming greets and gathers, /voice/respond handles each captured utterance, /voice/status closes the call — saving the conversation, analysing it with Claude, updating the child's stats and texting a summary plus a practice question home.

Africa's Talking loop

/at/incoming answers and records, /at/recording downloads the clip, transcribes it on Groq Whisper and replies, /at/events mirrors the Twilio status route for AT's event format.

Browser rehearsal

/api/sabi/voice-chat runs the identical pipeline — Groq Whisper, Claude Haiku, YarnGPT or ElevenLabs — against a microphone in a browser tab, so a lesson can be tested without spending a call.
