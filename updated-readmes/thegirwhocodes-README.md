## 🚀 Flagship Project

### Sabi / Education for Equality
**Status:** 🚀 **Launched** | Private source

Phone-accessible AI tutor for foundational literacy and numeracy in Nigeria. Designed for low-bandwidth settings where learners only have access to shared feature phones.

**What it demonstrates:**
- Telephony infrastructure (Twilio, Africa's Talking)
- Low-latency speech loops (STT → LLM → TTS < 3s)
- Curriculum-aware tutoring with Cambridge Grade 4 alignment
- Real-world deployment constraints and reliability engineering
- Full product lifecycle from research to deployed infrastructure

**Live:** [eduforequality.org](https://eduforequality.org) | [sabi.eduforequality.org](https://sabi.eduforequality.org)
