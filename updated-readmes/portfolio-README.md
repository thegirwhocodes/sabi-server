# Naomi Ivie — Portfolio

**Status:** 🚀 **Launched**

Personal portfolio showcasing founder-builder work in voice-first AI, education technology, and personal systems.

**Live:** https://naomiivie.vercel.app

---

## 🎯 Purpose

This site serves as a professional showcase and writing surface for product work, featuring:

- **Sabi** — Private flagship case study: phone-accessible AI tutor for Nigerian learners
- **Dactyl** — ASL translation glasses (Morgan Hacks 2026, 1st place)
- **Sage Mail** — Voice-first Gmail agent
- **Go** — iOS commitment device with Stripe penalties
- **Kai** — Adaptive focus coach
- **Ed.it** — Desktop AI video editing agent
- Additional projects: Bethel, Rings, Adjutant

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Typography:** Inter, Instrument Serif
- **Deployment:** Vercel
- **Design:** Editorial-focused, clean layouts, case study narrative structure
